# 社区舞蹈队 · 排练报名与演出走位协作台

React 18 + TypeScript + Zustand + Vite 实现的单页应用。围绕**同一场演出记录**，让队长、队员、服装负责人、文化站、音响师、志愿者六类角色协同完成：报名 → 排练签到 → 走位编排 → 服装 → 节目审查 → 演出当天 → 归档 的完整流程。

## 本地启动

```bash
npm install        # 安装依赖
npm run dev        # 开发模式，默认 http://localhost:5173
npm run build      # 类型检查 + 生产构建（输出 dist/）
npm run preview    # 预览生产构建，默认 http://localhost:4173
npm test           # 运行 store 层冒烟测试（22 项断言）
```

## 测试账号（角色）

本应用无登录密码，通过页面右上角下拉框切换角色即视为切换账号；选择「队员」时可再选择具体队员身份：

| 角色 | 主要页面 | 能做什么 |
|---|---|---|
| 队长 | 全部 | 发布报名、推进阶段、平板签到、上传曲目版本、标记动作分段与重点练习成员、编排走位、压缩队形、补传照片 |
| 队员 | 总览/报名/走位/服装/演出当天/档案/通知 | 查看自己的站位（蓝框标出）、报名节目、查看尺码与押金、接收通知 |
| 服装负责人 | 服装管理 | 收押金、登记领取（含家属代领）、上报并换货处理尺码问题、登记归还 |
| 文化站 | 文化站审核/排练室 | 查看节目主题/人数/时长/音响需求，场地审批、节目审查（通过/要求调整/不通过）、下发场地缩小通知、查看流程连续性 |
| 音响师 | 总览/演出当天/通知 | 查看各节目音响需求与当前曲目版本，接收版本更新通知 |
| 志愿者 | 演出当天/通知 | 按候场顺序引导节目、调整候场次序、发布现场临时通知、协助现场签到 |

预置数据：朝霞舞蹈队《丰收锣鼓》（走位阶段，含请假/前排缺席/尺码问题/场地缩小通知等异常场景）、《茉莉花·新编》（海选报名中）、夕阳红艺术团《张灯结彩》（演出当天候场中）、《歌唱祖国》（已归档，含照片与归还记录）。

## 功能与异常场景对照

- **报名**：队长发布广场舞/民族舞/合唱伴舞/节庆演出（可标记文艺汇演海选）；记录队员年龄、联系方式、服装尺码、可排练时间、是否参加正式演出、身体注意事项。
- **排练签到**：平板大按钮出勤/请假/缺席；上传曲目版本（自动通知音响师）；动作分段与重点练习成员标记；老年队员健康提醒条。
- **走位编排**：队形网格（前排高亮）；最近排练请假/缺席的队员站位标红闪烁，队长可快速发现前排缺席影响；队员点击放置/撤下；**场地缩小**一键压缩列数，被裁队员进入「待安置」并生成调整记录与通知；队形变化说明。
- **服装**：押金收取、本人/家属代领登记、归还退押金、尺码不合适上报与换货。
- **文化站**：节目主题/人数/时长/音响需求/场地审批；节目审查（「要求调整节目内容」会退回排练阶段）；报名→排练→走位→服装→审核→现场签到连续性链条；多支队伍排练室排期。
- **演出当天**：候场顺序（可提前/延后）、现场签到、现场临时通知、志愿者引导要点、音响需求确认。
- **演出档案**：签到汇总、服装归还、走位调整记录、现场照片、下次活动通知。
- **其他**：排练室多队共用（同时段同室冲突自动拦截）、老年队员健康提醒专页（按注意事项生成提醒建议）。

## 验证方式与结论

实际执行过的验证（2026-09-25）：

1. `npm run build`：TypeScript 严格模式类型检查 + Vite 生产构建通过。
2. `npm test`：store 层冒烟测试 **22/22 通过**，覆盖：报名生成服装押金记录、请假/缺席识别、走位唯一站位、场地缩小裁列（待安置+日志+通知）、曲目版本更新通知音响师、审查退回/通过流转、押金/家属代领/尺码换货/归还、排练室冲突拦截、现场签到、候场顺序调整、流程连续性判定。
3. `npm run dev` 启动后 `curl http://localhost:5173/` 返回 200；`npm run preview` 生产预览 `curl` 返回 200。

页面交互（点击放置站位、签到按钮、表单提交等）可在浏览器中按上表角色逐一操作验证。
